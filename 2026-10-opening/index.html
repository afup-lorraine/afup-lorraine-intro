Actu PHP


⚠️ Failles critiques (21 oct. 2026)

  • Deux RCE critiques : CVE-2026-109618 & CVE-2026-109619
  • CVSS 9.2 — exécution de code à distance, non authentifiée
  • Au cœur du moteur : mémoire (OOM) et état global résiduel

Qui est concerné ?

  • Toutes les installations servant du web
  • PHP-FPM, Apache mod_php, php-cgi, FrankenPHP, LiteSpeed
  • Risque maximal sur mod_php

Que faire ?

  • La mise à jour est la seule solution sûre
  • Correctifs : PHP 8.5.12 / 8.4.27 / 8.3.36 / 8.2.35
  • PHP 8.1 et antérieurs : backports source (7.4 / 8.0 / 8.1) ou vendor LTS
